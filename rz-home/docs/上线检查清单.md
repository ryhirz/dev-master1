## D. 生产安全项（⬜ 上线前必须完成）

| 项 | 操作 |
|---|---|
| SECRET_KEY | 生成强随机值并注入环境变量：`python -c "import secrets;print(secrets.token_urlsafe(48))"`（示例已入 `.env.example`） |
| 默认超管改密 | 后台「系统设置 → 管理员」编辑 admin 重置密码；或命令行：`POST /api/admin/admins/{id}`（带 super_admin token，body `{"password":"新密码"}`） |
| 演示账号清理 | 生产删除 editor/cs_hr 演示账号（seed 中 `demo_accounts` 段）或强制改密 |
| PG 最小权限 | 建独立应用账号，仅授 DML：`CREATE USER app_user ...; GRANT SELECT,INSERT,UPDATE,DELETE ON ALL TABLES IN SCHEMA public TO app_user;` |
| DATABASE_URL | 生产：`postgresql+psycopg2://app_user:***@db-host:5432/rz_home?sslmode=require` |
| CORS_ORIGINS | 限定真实域名（如 https://www.rzhome.com,https://admin.rzhome.com） |
| 上传目录 | UPLOAD_DIR 指向持久卷（compose 已挂 `uploads` 卷） |
