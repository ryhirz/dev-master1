## 1. 项目概述

高端全屋智能家居企业官网 + 管理后台，覆盖营销展示与运营管理全链路。

- **定位**：全屋智能整装（灯光/安防/影音/睡眠/能源五大系统），高端品牌调性，白底荧光蓝科技风。
- **形态**：Monorepo 单仓库（backend + frontend/web 前台 + frontend/admin 后台）。
- **用户**：访客（浏览/留言/投递）、后台管理员（super_admin / editor / cs_hr 三角色）。

## 2. 技术架构

| 端 | 技术栈 | 端口 |
|---|---|---|
| backend | Python 3.13 · FastAPI · SQLAlchemy 2.0 · Pydantic v2 · Alembic · JWT · bcrypt 4.0.1 | 8000 |
| frontend/web | Vite 5 · React 18 · TS · Tailwind 3 · React Router | 5173 (dev) |
| frontend/admin | Vite 5 · React 18 · TS · Ant Design 5 · Tiptap 富文本 · Vitest | 5174 (preview) |
| DB | dev: SQLite（`backend/rz_home.db`）；prod: PostgreSQL 16（docker compose）+ Redis 7 | — |

- 响应信封统一：`{code, message, data, request_id}`，code=0 成功。
- 鉴权：JWT（access 30min + refresh 7d），BCrypt 密码哈希。
- 业务表均含 `created_at` / `updated_at`（ORM server_default + onupdate）。`audit_log` 为**追加型审计表，仅 `created_at`**（设计上不可变，故无 `updated_at`）。**审核修正**：`admin_user.updated_at` 此前缺失（管理员列表「修改时间」列恒空），已补列（模型 `AdminUser` + Schema `AdminUserOut` + Alembic 迁移 `20260821_add_admin_user_updated_at`）。

## 13. 快速启动

```bash
# 方式一：一键（Windows PowerShell）
powershell -ExecutionPolicy Bypass -File rz-home/start.ps1

# 方式二：手动
cd rz-home/backend && ENV=dev python -m uvicorn app.main:app --port 8000
cd rz-home/frontend/web && npm run dev          # :5173
cd rz-home/frontend/admin && npm run preview -- --port 5174   # :5174
```

访问：前台 http://localhost:5173 ｜ 后台 http://localhost:5174（admin/admin123）｜ API 文档 http://localhost:8000/docs
