# 必须锁 bcrypt 版本：passlib==1.7.4 与 bcrypt>=5.0.0 不兼容。
# 本机三版本对照实证（passlib 1.7.4 固定）：
#   bcrypt 4.0.1 -> 短密码 hash/verify 均正常
#   bcrypt 4.3.0 -> 仅打印 "(trapped) error reading bcrypt version" 告警，hash/verify 仍正常（__about__ 缺失无害）
#   bcrypt 5.0.0 -> 连 12 字符短密码都抛 ValueError: password cannot be longer than 72 bytes
# 真因不是"版本探测报错"，而是 bcrypt 5.0.0 起 hashpw 对 >72 字节密码由「静默截断」改为「抛 ValueError」，
# 而 passlib 初始化时会用长密码做后端自检探测 —— 与用户输入无关，一旦不兼容则全部哈希/校验失败。
