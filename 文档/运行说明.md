# Rz家居 全栈项目运行说明

## 1. 项目简介

Rz家居 企业官网与后台管理系统，包含：

- **前台官网**：React 18 + Vite + Tailwind CSS，端口 5173
- **后台管理**：React 18 + Vite + Tailwind CSS，端口 5174
- **后端 API**：FastAPI + SQLAlchemy 2.0 + SQLite（开发），端口 8000

参考站点形态：品牌展示 + 加盟/联系入口 + 招聘入口，无电商交易。

## 2. 默认访问地址

| 服务 | 地址 | 说明 |
|------|------|------|
| 前台官网 | http://localhost:5173 | 面向访客 |
| 后台管理 | http://localhost:5174 | 默认账号 `admin / admin123` |
| 后端 API | http://127.0.0.1:8000 | API 文档 http://127.0.0.1:8000/docs |

## 3. 环境要求

- Python 3.10+（推荐 3.13）
- Node.js 18+（推荐 22 LTS）
- npm 或 pnpm

> 本仓库 `frontend/` 与 `frontend-admin/` 使用相同依赖。若环境与中国大陆网络相似，建议复用 `frontend/node_modules` 到 `frontend-admin/node_modules`，避免重复安装 antd/作用域包导致超时。

## 4. 启动步骤

### 4.1 启动后端

```bash
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

首次启动会自动：
- 创建 SQLite 数据库 `backend/app/rz_home.db`
- 创建三角色（super_admin / editor / cs_hr）
- 创建默认超管 `admin / admin123`
- 写入示例数据（产品、案例、新闻、职位、轮播图、里程碑）

### 4.2 启动前台官网

```bash
cd frontend
npm run dev
```

### 4.3 启动后台管理

```bash
cd frontend-admin
npm run preview
```

> **重要**：在本机环境中，`npm run dev`（Vite dev server）会因依赖预构建触发 safe-delete 超时崩溃，因此后台管理固定使用 `npm run preview`。

## 5. 一键启动脚本（Windows PowerShell）

已提供 `start-all.ps1`，在项目根目录执行：

```powershell
.\start-all.ps1
```

该脚本会依次启动后端、前台、后台三个服务，并输出各自的访问地址。

## 8. 图片上传说明

- 上传接口：`POST /api/admin/upload`（需要 editor 及以上角色）
- 支持格式：jpg、jpeg、png、gif、webp、svg
- 文件存储：`backend/app/uploads/`
- 访问路径：`/uploads/{文件名}`
- 数据库字段：`images` 为 JSON 数组，如 `["/uploads/xxx.jpg"]`

## 9. 生产部署建议

1. **数据库**：将 `backend/app/database.py` 中的 SQLite 替换为 PostgreSQL。
2. **密钥**：修改 `backend/app/security.py` 中的 `SECRET_KEY` 与 `ALGORITHM`，并使用环境变量注入。
3. **密码**：立即修改默认管理员密码。
4. **CORS**：通过环境变量 `CORS_ORIGINS` 配置允许来源，例如：
   ```bash
   CORS_ORIGINS=https://www.rzhome.com,https://admin.rzhome.com
   ```
5. **静态资源**：生产环境建议用 Nginx 反代 `/uploads`，并配置缓存。
6. **前端构建**：
   ```bash
   cd frontend && npm run build
   cd ../frontend-admin && npm run build
   ```
   产物分别在 `dist/` 目录，可通过 Nginx / CDN 托管。

## 10. 常见问题

**Q：后台 `npm run dev` 崩溃怎么办？**  
A：使用 `npm run preview`。dev 模式在本机触发依赖预构建超时，preview 为生产构建预览，功能一致。

**Q：后台依赖安装慢或失败？**  
A：复用 `frontend/node_modules` 到 `frontend-admin/node_modules`，两个项目依赖完全相同。

**Q：上传图片后前台不显示？**  
A：确认后端已启动且 `/uploads` 目录存在；确认 `images` 字段保存的是以 `/uploads/` 开头的路径数组。

**Q：如何重置数据库？**  
A：删除 `backend/app/rz_home.db` 后重启后端，种子数据会自动重新生成。
