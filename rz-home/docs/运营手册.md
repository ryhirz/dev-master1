# Rz家居 全栈项目 · 运营手册

> 面向内容运营 / 客服 HR 的日常操作指南（后台地址与账号见《运行说明.md》）

## 1. 角色与权限

| 角色 | 账号（演示） | 可访问模块 | 说明 |
|---|---|---|---|
| 超级管理员 | admin / admin123 | 全部模块 + 管理员 + 角色权限 | 首次部署后务必改密 |
| 内容编辑 | editor / editor123 | 系列/分类/产品/案例/新闻/关于/轮播 | 官网内容维护 |
| 客服/HR | cs_hr / cshr123 | 招聘管理、留言管理（banner 只读） | 处理求职与客户留言 |

> 管理入口的左侧菜单已按角色自动过滤；后端接口同样有权限校验（越权返回 403）。

## 2. 常用操作

### 2.1 产品上新（内容编辑）
1. 左侧「产品」→「新增」。
2. 填写名称/型号/价格，选择系列与分类。
3. 「产品图片」可**一次上传多张**（保存为 JSON 数组，第一张作封面）。
4. 「规格参数」逐行添加（如 材质/尺寸/颜色）。
5. 勾选「首页推荐」→ 保存 → 前台首页推荐区即时更新。

### 2.2 发布新闻（内容编辑）
1. 左侧「新闻」→「新增」。
2. 选分类（企业新闻/行业资讯）、作者、状态（草稿/已发布）、发布时间。
3. 正文使用**富文本编辑器**（加粗/标题/列表/引用），保存时后端自动净化 HTML。
4. 发布后前台「新闻中心」可见；置顶勾选后列表置顶。

### 2.3 案例维护（内容编辑）
- 「案例」→ 新增/编辑：分类（住宅/工程/商业）、封面图、图集（多图）、「NEW」标记。
- 前台「新案例」板块优先展示 is_new 的启用案例。

### 2.4 处理留言（客服/HR）
1. 「留言管理」按类型（在线留言/求职意向）与状态筛选。
2. 打开「处理/回复」：填写回复内容、设置状态（已处理/已忽略）→ 保存。
3. 删除：对已无用的留言可直接删除（软删）。

### 2.5 招聘职位（客服/HR）
- 「招聘管理」→ 新增职位，选类型（社会/校园）、部门、城市、薪资、招聘人数。
- 状态「发布中」= 前台可见；「已下架」= 前台隐藏。

### 2.6 轮播与公司信息
- 「轮播管理」：上传 1920×720 宽幅图，排序越小越靠前，停用即前台隐藏。
- 「关于我们」→「公司信息」：电话/邮箱/地址/荣誉数等修改后**前台全站同步生效**；
  「关于区块」维护 overview/brand 文案；「发展历程」维护时间轴里程碑。

### 2.7 权限与账号（仅超级管理员）
- 「管理员」：新建/编辑管理员、分配角色、重置密码（编辑时留空不改）、启用/禁用。
- 「角色权限」：勾选 13 个模块的 查看/编辑 权限；保存后即时生效（该角色下次请求起）。

## 3. 日常巡检建议
- 每周：查看「控制台」待处理留言数（有橙色告警即处理）。
- 每月：核对产品/案例/新闻内容是否过期；查看「数据统计」内容分布。
- 发布前：先存「草稿」预览，确认后改为「已发布」。
