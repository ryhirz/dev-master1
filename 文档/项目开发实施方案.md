## 一、目标与交付范围

**交付物（v1）**
- 前台官网系统：React 18 + TypeScript + Vite + Tailwind CSS，5 主导航 + 二级，共 12 类路由页面。
- 后台管理系统：React 18 + TypeScript + Vite + **Ant Design 5（默认假设，待确认）**，登录 + 三角色权限 + 11 类路由页面。

- 配套：Docker 部署脚本（开发可运行）、接口文档（FastAPI Swagger）、种子数据、测试。

**非目标（继承 PRD 1.5 Non-goals）**：在线商城/支付、前台会员、多语言、CMS 自定义装修、营销自动化、招商加盟、暗色模式（v2）。

| 层 | 技术 | 说明 |

## 四、数据库落地策略（14 表 / 双库 / 种子）

**权威来源**：`数据库设计文档` §4 / `开发技术文档` §4。14 张表：

业务核心域：`product_series`、`category`（自引用 parent_id）、`product`、`cases`（避关键字）、`news`、`job`
互动与内容域：`message`（type=contact/job_application，`ref_id→job.id`）、`banner`、`company_info`（单行 id=1）、`about_section`（code=overview/brand）、`milestone`
权限与安全域：`role`（super_admin/editor/cs_hr）、`admin_user`、`audit_log`（P1 建表、v1 仅记录登录与关键写）

**关键约定**
- 枚举值在 Pydantic 校验，**不在 DB 建 CHECK**（保证 SQLite/PG 一致）。
- `updated_at` 由 ORM `onupdate` 维护（DB 无 ON UPDATE 触发器）。
- JSON 用 ORM `JSON` 类型（PG jsonb / SQLite TEXT 透明）。
- 软删除用 `status` 标记，不做物理删除。
- 索引：外键列 + 高频筛选列（status/type/category/created_at）+ 唯一键（slug/username/role.name）。

**种子（首次启动自动执行，对齐运行说明）**
- 三角色：super_admin（全量 `{"*":["read","write"]}`）、editor（展示型内容）、cs_hr（job/message 写 + banner 读）。
- `company_info` 单行（id=1，Rz家居占位）。
- 默认超管：`admin / admin123`（**默认假设，首次部署须改密**；密码哈希由后端 bcrypt 生成，禁止明文落 SQL）。
- 示例数据：产品/案例/新闻/职位/轮播/里程碑若干（便于演示，可配置开关）。

**迁移**：Alembic 双库兼容（`op.*` 跨库 API），本地 SQLite `upgrade head` 验证，CI 用 PG 容器校验。

## 五、后端接口落地策略（38 接口）

**契约来源**：`开发技术文档 §5`。统一响应信封 `{code, message, data, request_id}`；分页 `{items,page,page_size,total}`；错误码 1001/1002/1003/2001–2005/3001/3002/429/5000。

**公开接口（16）**：`/api/home/overview`、`/api/series`、`/api/products`(+id)、`/api/cases`(+id)、`/api/news`(+id)、`/api/about/overview`、`/api/about/history`、`/api/about/brand`、`/api/contact/info`、`/api/jobs`(+id)、`/api/banners`、`POST /api/inquiries`。
**管理接口（22，JWT 必需，require_role 授权）**：login/refresh/logout/me、series、categories、products、cases、news、jobs、messages(+id)、banners、company-info、about-sections、milestones、upload、admins、roles、stats/overview。

**鉴权**：AccessToken 30min 携带 `Authorization: Bearer`；过期 401→前端用 RefreshToken 调 `/refresh` 换新并重试；Refresh 失效→跳登录；`/logout` 将 RefreshToken 加入吊销名单（Redis 或 DB）。

**实现顺序**：config/db → models → schemas → security(deps) → 公开接口 → 管理接口 → upload → stats → 限频(预留) → Alembic 迁移 + 种子。

## 六、前台官网实现要点（12 路由，对齐原型+UI/UX §3/§6）

路由：`/`（首页）、`/products`、`/products/:id`、`/cases`、`/cases/:id`、`/news`、`/news/:id`、`/jobs`、`/jobs/:id`、`/about`、`/about/history`、`/about/brand`、`/about/contact`、`/404`。

- **全局框架**：顶部导航（对齐 `prototype_topnav.html` 5 主导航 + 二级下拉/移动抽屉）、页脚（三栏 + 版权/ICP 占位）、面包屑、响应式（断点 375/768/1024/1440）。
- **设计令牌**：Tailwind 注入 `cream/walnut/walnut-d/sand/ink/muted/line` + 语义色（success/warning/danger）；字体 Noto Serif SC（标题）/ Noto Sans SC（正文）；`index.css` 注入 UI/UX §2.2 CSS 变量。
- **页面要点**：
  - 首页：轮播(Hero) + 品牌定位 + 企业实力(company_info，未配置不渲染) + 推荐产品 + 最新案例/新闻 + 招聘 CTA。
  - 产品中心：系列卡 + 筛选(series/category/keyword) + 分页 + 详情(图集/规格定义列表/相关推荐)；`hidden`→404。
  - 案例：分类(住宅/工程/商业)筛选 + `is_new` 优先 + 详情。
  - 新闻：Tab(company/industry) + 置顶 + 仅 published 可见。
  - 招聘：Tab(social/campus) + 详情 + 投递意向表单→`POST /api/inquiries`(type=job_application,job_id)。
  - 关于我们四页：overview(history/brand/contact 数据均来自 company_info/about_section/milestone)；联系表单→`type=contact`。未配置显示占位文案。
- **状态/异常**：骨架屏、空态、错误/网络重试、404 品牌页；表单 loading 禁用 + 校验就近红字 + Toast。
- **SEO/无障碍（P1 取舍见 §12）**：每页 title/description、语义标签、`sitemap.xml`/`robots.txt`、焦点环、`img alt`、`aria-*`、`prefers-reduced-motion`。
